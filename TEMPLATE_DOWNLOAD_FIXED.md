## 🎯 Langkah Menggunakan Template

### **1. Download Template**
```
Dashboard → [Berita/Kegiatan] → Import CSV → Download Template CSV
```

### **2. Buka di Excel**
- Klik 2x file `.csv` → Excel akan membuka otomatis
- Atau: Kanan click → Open with → Excel

### **3. Isi Data Anda**
- Jangan ubah header (baris pertama)
- Mulai isi dari baris ke-2
- Tambah baris baru sesuai kebutuhan

### **4. Save File**
- **Penting!** Save sebagai CSV, bukan Excel
- Klik File → Save As
- Pilih format: **CSV (Comma delimited)**
- Klik Save

### **5. Upload ke Dashboard**
- Buka halaman Import → Upload file
- Klik "⬆️ Import Berita/Kegiatan Sekarang"
- Selesai! ✅

## ❓ FAQ

**Q: Bisa tidak buka template dengan aplikasi lain?**  
A: Bisa! CSV bisa dibuka dengan: Excel, Google Sheets, LibreOffice, Notepad, dll

**Q: Harus save sebagai CSV?**  
A: Ya! Jika save sebagai Excel (`.xlsx`), upload akan error

**Q: Bisa copy-paste dari Excel?**  
A: Bisa! Tapi pastikan format sudah benar sebelum upload

**Q: Berapa baris maksimal bisa import?**  
A: Tidak ada batasan jumlah baris, asalkan file max 5 MB
